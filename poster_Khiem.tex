\begin{block}{Giới thiệu vấn đề}
Trong bối cảnh chuyển đổi số và sự bùng nổ của dữ liệu lớn (Big Data), các hệ thống thông tin hiện đại
phải xử lý dữ liệu phân tán và dữ liệu luồng thời gian thực với hiệu năng cao.
Tối ưu hóa truy vấn và khả năng mở rộng là những thách thức quan trọng trong các kiến trúc hiện đại.
\end{block}

\begin{block}{Mục tiêu nghiên cứu}
\begin{itemize}
    \item Phân tích các kỹ thuật xử lý dữ liệu phân tán
    \item Đánh giá hiệu năng xử lý luồng dữ liệu
    \item So sánh các nền tảng phổ biến
    \item Đề xuất hướng phát triển hệ thống
\end{itemize}
\end{block}

\begin{block}{Phương pháp nghiên cứu}
\begin{itemize}
    \item Nghiên cứu tài liệu khoa học (Google Scholar, IEEE)
    \item Phân tích kiến trúc hệ thống
    \item Tổng hợp và đánh giá kết quả
\end{itemize}
\end{block}

Spark Streaming phù hợp với các hệ thống kết hợp batch và streaming.
Storm đơn giản nhưng kém hiệu quả trong môi trường dữ liệu lớn.
